> Part of the [games](https://github.com/Lantieridev/games) monorepo.

A premium, minimalist Hangman game built with Vanilla JavaScript and CSS. Part of the Lantieridev portfolio.

## Features
- **Premium Design**: Glassmorphism aesthetic with dark mode support.
- **Dynamic Categories**: Randomly selected word categories (Technology, Programming, Cybersecurity).
- **Attempts meter**: a row of pips shows exactly how many guesses are left, alongside the per-guess feedback message.
- **Persistence**: Win count tracked via LocalStorage.
- **Robust Logic**: 28 tests (Vitest + jsdom), 100% line/branch/function coverage, enforced in CI.
- **Responsive**: Mobile-friendly design.

## Tech Stack
- HTML5 / Vanilla CSS
- JavaScript (ES6+)
- Vitest (Testing)
- JSDOM (Testing environment)

## Setup
1. Clone the repository.
2. Run `npm install` to install testing dependencies.
3. Run `npm test` to verify the logic (`npm run test:coverage` for the coverage report).
4. Open `index.html` in your browser to play.

# El Ahorcado

Un juego de el ahorcado minimalista y premium construido con JavaScript y CSS puro. Parte del portfolio de Lantieridev.

## Características
- **Diseño Premium**: Estética de Glassmorphism con soporte para modo oscuro.
- **Categorías Dinámicas**: Categorías de palabras seleccionadas al azar (Tecnología, Programación, Ciberseguridad).
- **Medidor de intentos**: una fila de indicadores muestra cuántos intentos quedan, junto al mensaje de feedback de cada intento.
- **Persistencia**: Contador de victorias persistente mediante LocalStorage.
- **Lógica Robusta**: 28 tests (Vitest + jsdom), 100% de cobertura línea/rama/función, verificado en CI.
- **Responsivo**: Diseño adaptado a dispositivos móviles.

## Tecnologías
- HTML5 / CSS Puro
- JavaScript (ES6+)
- Vitest (Testing)
- JSDOM (Ambiente de pruebas)

## Configuración
1. Clonar el repositorio.
2. Ejecutar `npm install` para instalar dependencias de prueba.
3. Ejecutar `npm test` para verificar la lógica (`npm run test:coverage` para el reporte de cobertura).
4. Abrir `index.html` en tu navegador para jugar.
