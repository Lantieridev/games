Welcome to **Elemental Domain Engine**, a deep dive into advanced Object-Oriented Design and domain-driven logic. This project serves as a robust backend for handling complex state transitions and entity behaviors.

---

## 🚀 Key Features

*   **🧩 Complex Entity Logic:** Implements sophisticated business rules and state machines for domain entities.
*   **📐 Algorithmic Validation:** Features high-performance validation layers for coordinate systems and logical constraints.
*   **🛠️ OOP Excellence:** Demonstrates mastery of Inheritance, Polymorphism, and Design Patterns (Strategy, Factory).
*   **🧪 Comprehensive Testing:** 78 tests (JUnit 5), 96%+ line / 87%+ branch coverage, enforced in CI via a JaCoCo gate. Includes a genuine end-to-end run of the real entry point (`App.main()`) driven through simulated console I/O with a seeded, reproducible shuffle — not just isolated unit tests.

---

## 🛠️ Tech Stack

*   **Java 21**: Modern language constructs for robust domain modeling.
*   **Maven**: Build automation and dependency management.
*   **JUnit 5**: Full test coverage for domain logic.
*   **GitHub Actions**: Automated CI/CD pipeline.

---

## 📖 How to Run

### 1. Build and Test
```powershell
mvn clean install
```

### 2. Compile and Validate
```powershell
mvn compile
```

### 3. Run with coverage gate
```powershell
mvn verify
```
